TROUBLESHOOTING:
-------------------------------------------------------------------------------
Q: I don't see the optimization messages
A: Make sure you're running the modified demo_gradio.py in:
   current/FramePack-main/demo_gradio.py

Q: No speedup observed
A: 1. Check GPU usage: watch -n 1 rocm-smi
   2. Verify Flash SDP: python -c "import torch; print(torch.backends.cuda.flash_sdp_enabled())"
   3. Ensure VRAM not oversubscribed

Q: Performance worse than before
A: 1. Increase gpu_memory_preservation slider (try 10-12 GB)
   2. Temporarily disable torch.compile: export FRAMEPACK_USE_TORCH_COMPILE=0
   3. Disable tritonBLAS if conflict: export FRAMEPACK_USE_TRITONBLAS=0

Q: CK attention patching fails
A: It's optional! Flash Attention already uses CK automatically.
   Direct patching is just an additional 5-15% boost.
